# UAT scenarios

116 scenarios. Generated from `scenarios.py` by `build_uat.py` - edit there, not here. Testers normally work in the spreadsheet `UAT-scenarios.xlsx` (same content, with drop-down Pass/Fail cells and a summary); this file is the printable / reviewable copy. How to run the exercise: [README.md](README.md).

**Order:** run the *Owner* scenarios first (UAT-OWN-01 to 05 create the people everybody else uses), then Manager, then Employee, then the cross-cutting checks. Scenarios that need another scenario's result say so in their steps.

Result values: **Pass**, **Fail**, **Blocked** (could not run), **N/A**. Write what actually happened in *Actual result* (always for a Fail), anything else in *Notes*.
